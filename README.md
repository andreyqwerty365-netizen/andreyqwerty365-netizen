## Как я работаю

- разбиваю спецификацию на проверяемые этапы;
- довожу задачу до запускаемого результата, а не только до исходного кода;
- добавляю автоматические проверки для критической бизнес-логики;
- сохраняю обратную совместимость данных и продумываю восстановление после сбоев;
- отделяю рабочие данные, секреты и приватные ключи от публичного репозитория;
- фиксирую версии через понятные коммиты, теги и releases.
